# Contributing to Awesome Agent Harness

Thanks for your interest in contributing! This is a curated list, so quality matters more than quantity.

## How to Add an Entry

1. **Fork** this repository.
2. **Add your entry** to the appropriate section in both `README.md` and `README_zh.md`.
3. **Submit a pull request** with a clear description of what you're adding and why.

## Entry Format

Every entry must follow this format:

```markdown
- **[Title](URL)** — Author/Org — *type, date* — One-sentence annotation explaining what it is and why it belongs here.
```

### Markers

- `🆕` — Released or substantially updated in 2025–2026
- `⚠️` — Caveat (unverified URL, discontinued, etc.)

### Types

Use one of: `blog`, `paper`, `talk`, `docs`, `tool/repo`, `benchmark`, `spec`, `book`, `newsletter`, `podcast`

## Quality Criteria

Before submitting, ask yourself:

1. **Is this a primary source?** Original research, engineering blog posts from practitioners, official documentation, and foundational papers are preferred over summaries, listicles, or derivative commentary.
2. **Does the annotation say WHY?** Not just what it is, but why someone should read it. What makes it non-obvious or load-bearing?
3. **Is the URL verified and accessible?** Dead links, paywalled content (without noting it), and placeholder URLs are not acceptable.
4. **Is it in the right section?** If it spans multiple sections, place it in the most relevant one and add a cross-reference note.

## What We Don't Accept

- Marketing content disguised as technical writing
- Entries without annotations (link dumps)
- Duplicate entries (check both language versions first)
- Content that is purely about the model, not the harness
- Entries with unverified or broken URLs

## Bilingual Requirement

This is a bilingual (EN/中文) list. When adding entries:

- Add to **both** `README.md` and `README_zh.md`
- The Chinese version doesn't need to be a word-for-word translation — adapt the annotation for a Chinese-speaking audience
- If you can only contribute in one language, that's fine — note it in the PR and someone will help with the translation

## Section Proposals

Want to add a new section? Open an issue first to discuss whether it fits the scope. The scope is: **everything that wraps around an AI agent model to make it work reliably** — architecture patterns, context engineering, tool design, skills, memory, orchestration, evaluation interaction, and production practices.

## Code of Conduct

Be kind, be constructive, be specific. This is a learning resource, not a competitive arena.
